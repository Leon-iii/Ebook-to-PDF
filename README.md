# E-book 화면 캡처 PDF

정상적으로 화면에 표시되는 e-book 페이지의 지정 영역을 순서대로 캡처해 하나의 PDF로 정리하는 Windows용 도구입니다. DRM이나 캡처 방지 기능을 우회하지 않으며, 이용 중인 콘텐츠와 서비스의 약관 및 관계 법령이 허용하는 범위에서만 사용하세요.

## 설치 및 실행

```powershell
uv sync
uv run ebook-to-pdf
```

또는 `run.ps1`을 실행해도 됩니다.

## 사용 순서

1. e-book 뷰어에서 캡처를 시작할 페이지를 열어 둡니다.
2. 좌표를 직접 입력하거나 **드래그로 지정**을 눌러 캡처 영역을 선택합니다. 선택 대기 중 ESC를 누르면 취소됩니다.
3. 캡처 영역 바깥쪽에만 표시되는 테두리의 변이나 모서리를 드래그해 영역을 미세 조정할 수 있습니다. 테두리 색상과 굵기는 변경할 수 있으며, 옆에 현재 영역 크기가 표시됩니다. 일시정지 중 영역을 바꾸면 재개하는 페이지부터 새 영역이 적용됩니다.
4. **시험 캡처**를 눌러 페이지를 넘기지 않고 실제 캡처 결과를 미리 확인합니다.
5. 현재 페이지, 총 페이지, 다음 페이지 키를 입력합니다. 키 기본값은 오른쪽 화살표(`→`)입니다.
6. **창 목록 새로고침** 후 대상 e-book 창을 선택합니다.
7. 파일 이름과 저장 폴더, 시작/페이지 전환 대기 시간을 확인합니다.
8. **실행**을 누릅니다. 앱이 최소화되고 대상 창에 포커스를 맞춘 뒤 캡처합니다.
9. 실행 중 ESC 또는 **일시정지**를 누르면 멈추고, **재개**를 누르면 이어서 진행합니다. **정지**하면 지금까지 캡처된 페이지를 PDF로 저장합니다.

지원하는 다음 페이지 키는 방향키, Space, Enter, PageDown, PageUp, Home, End, F1~F20 및 단일 문자입니다.

## 안전 검사와 작업 복구

- 화면 변경 감지를 켜면 페이지 넘김 후 화면이 실제로 달라질 때까지 기다립니다. 최대 대기 시간을 넘기면 자동 일시정지합니다.
- 중복 페이지 감지를 켜면 직전 페이지와 같은 화면을 PDF에 넣지 않고 자동 일시정지합니다.
- 대상 창의 포커스가 다른 창으로 이동하면 잘못된 화면을 저장하기 전에 자동 일시정지합니다.
- 진행 중에는 예상 남은 시간이 상태 줄에 표시됩니다.
- 캡처된 PNG와 진행 정보는 각 페이지 직후 앱 전용 복구 폴더에 기록됩니다. 비정상 종료 후 프로그램을 다시 열면 이어서 진행하거나 캡처 완료분의 PDF 생성을 마칠 수 있습니다.

설정은 `%LOCALAPPDATA%\\ebook-to-pdf\\settings.json`에 자동 저장되어 다음 실행 때 복원됩니다. 복구 데이터는 정상적으로 PDF가 작성되거나 사용자가 정지한 뒤 자동 삭제됩니다.
