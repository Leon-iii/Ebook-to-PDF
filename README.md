# E-book 화면 캡처 PDF

정상적으로 화면에 표시되는 e-book 페이지의 지정 영역을 순서대로 캡처해 하나의 PDF로 정리하는 Windows용 도구입니다. DRM이나 캡처 방지 기능을 우회하지 않으며, 이용 중인 콘텐츠와 서비스의 약관 및 관계 법령이 허용하는 범위에서만 사용하세요.

## 설치 및 실행

```powershell
uv sync
uv run ebook-to-pdf
```

또는 `run.ps1`을 실행해도 됩니다.

## 사용 순서

1. e-book 뷰어에서 캡처를 시작할 페이지를 열어 둡니다.
2. 좌표를 직접 입력하거나 **드래그로 지정**을 눌러 캡처 영역을 선택합니다. 선택 대기 중 ESC를 누르면 취소됩니다.
3. 캡처 영역 바깥쪽에만 표시되는 4px 빨간 테두리의 변이나 모서리를 드래그해 영역을 미세 조정할 수 있습니다. 일시정지 중 영역을 바꾸면 재개하는 페이지부터 새 영역이 적용됩니다.
4. 현재 페이지, 총 페이지, 다음 페이지 키를 입력합니다. 키 기본값은 오른쪽 화살표(`→`)입니다.
5. 파일 이름과 저장 폴더, 시작/페이지 전환 대기 시간을 확인합니다.
6. **실행**을 누릅니다. 앱이 최소화된 뒤 시작 대기 시간이 지나면 캡처합니다.
7. 실행 중 ESC 또는 **일시정지**를 누르면 멈추고, **재개**를 누르면 이어서 진행합니다. **정지**하면 지금까지 캡처된 페이지를 PDF로 저장합니다.

지원하는 다음 페이지 키는 방향키, Space, Enter, PageDown, PageUp, Home, End, F1~F20 및 단일 문자입니다.

설정은 `%LOCALAPPDATA%\\ebook-to-pdf\\settings.json`에 자동 저장되어 다음 실행 때 복원됩니다. 페이지 이미지는 임시 폴더에만 저장되고 PDF 작성 후 삭제됩니다.
